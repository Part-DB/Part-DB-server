# Upgrade

This section provides information on how to upgrade Part-DB to the latest version.
This is intended for major release upgrades, where requirements or things change significantly.

# Update

Instructions on how to install routine updates for Part-DB are found in the installation directory instead. For instance, if you installed via Docker, you'd refer to [the update section of the Docker install page](https://docs.part-db.de/installation/installation_docker.html#update-part-db).
